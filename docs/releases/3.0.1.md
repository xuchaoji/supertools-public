# 3.0.1 发布说明（AG）

> 构建日期：2026-11-22
> 版本：`3.0.1`（versionCode `3000001`）
> 目标：AppGallery（product=release，`IS_AG_TARGET = true`）

## 产物

- 签名包：`build/outputs/release/supertools-public-release-signed.app`
- 未签名包：`build/outputs/release/supertools-public-release-unsigned.app`
- 包内模块：`main-product.hap` + `notes_hsp-default.hsp`
- 签名包体积：约 15.8MB（压缩后）
- SHA256：`BF9C11C33203A18108405938E1882194A1ED275438A400884BD97DF8AE6BAD5A`

## 本版变更

- 新增 Markdown 笔记：列表、编辑器、预览、搜索、删除确认、自动保存、本地文件存储。
- Markdown 笔记使用独立 HSP，与宿主 HAP 一起安装；HSP 导出完整功能组件，宿主只保留路由壳。
- 删除确认使用官方 `AlertDialog` + `uiMaterial.ImmersiveMaterial`；应用级开启 `ohos.arkui.UIMaterial.state`。
- 内容区按官方 FAQ 使用 `backgroundColor` + `backgroundBlurStyle`/`backdropBlur` 兜底，不伪造系统材质。
- 修复全应用深色判断：`(display-mode: dark)` → `(dark-mode: true)`，关闭光感时工具箱卡片和设置文字不再出现白底白字/黑底黑字。
- Router、AdsKit、Ads Hsp、模拟游戏四个开发者入口默认隐藏；设置页连点彩蛋仍可解锁。
- Markdown 入口图标改为与工具箱一致的线性风格；入口描述不再出现 HSP/渲染库名称。

## AG 上传检查

1. 上传 `supertools-public-release-signed.app`。
2. 确认包内版本：`pack.info` 为 `3.0.1 / 3000001`。
3. 确认 `main-product.hap` 权限中没有 `ohos.permission.SYSTEM_FLOAT_WINDOW`（release product 已由自定义 hvigor 插件移除）。
4. 确认包内有 `notes_hsp-default.hsp`（Markdown 笔记依赖）。
5. 发布前在 release 签名环境真机安装一次，验证启动、Markdown 入口、深色/浅色、广告测试入口默认隐藏。
